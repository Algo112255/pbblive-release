# 📢 PBBLIVE 2.0 — Announcement

**PBBLIVE 2.0 is live.** Both Mobile and PC builds are updated.

## What's new
- **New PBBLIVE house icon** on Mobile and PC
- **Chat is working again** on Mobile — read and send restored
- **Auto-update on Mobile** — the app checks for a new version on startup and opens the download automatically
- **Donate now opens GitHub** — QR codes for GCash and MariBank are hosted here in the `donate/` folder
- **Portrait mode** works on Mobile
- **Announcements** are now posted here on GitHub instead of popping up inside the app
